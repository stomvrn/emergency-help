## Что это

Экстренная помощь простыми словами для людей без медицинского образования. 16 карточек: 14 алгоритмов первой помощи (СЛР, инсульт, инфаркт, кровотечение, подавился, судороги, ожог, отравление, обморожение, утопление, анафилаксия и др.) и 2 справки (как вызвать скорую, закон о помощи).

**Не медизделие.** Справочно-образовательный инструмент. Не предназначен для диагностики, лечения или клинических решений.

## Принципы

- **Офлайн.** Работает без сети. Данные не покидают устройство.
- **Zero dependencies.** Нет CDN, нет внешних скриптов, нет телеметрии.
- **CSP.** `default-src 'none'; connect-src 'none'`.
- **Single-file.** Один HTML, без сборки. Открывается в любом браузере.
- **Крупный шрифт.** Для чтения в стрессе.
- **Бесплатно.** CC0 · Public Domain. Копируй, печатай, отправляй.
