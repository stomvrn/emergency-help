# Как помочь проекту

Спасибо за интерес!

## Что можно предложить

- Исправление ошибок в медицинских алгоритмах
- Улучшение формулировок (проще, короче, яснее)
- Дополнение примерами
- Перевод на другие языки
- Улучшение вёрстки для мобильных
- Изменение порядка отображения алгоритмов

## Как это сделать

1. Форкните репозиторий
2. Создайте ветку (`git checkout -b fix/nazvanie`)
3. Внесите правки в `index.html`
4. Запустите проверки локально (см. `.github/workflows/ci.yml`)
5. Откройте Pull Request с описанием

## Что важно

- Инструмент работает **офлайн** — не добавляйте сетевые запросы
- Инструмент работает **в одном файле** — не разбивайте на модули
- **Ноль зависимостей** — никаких CDN, npm, внешних скриптов
- **Медицинский контекст** — все утверждения должны иметь источник

## Медицинские правки

Если вы врач, фельдшер или преподаватель первой помощи — особенно ценен ваш вклад.

Требования к правкам в алгоритмах:

1. **Источник обязателен.** Ссылка на приказ, клиническую рекомендацию, методическое пособие.
2. **Без личного опыта.** «У меня в практике было» — не подходит. Только официальные источники.
3. **Проверьте применимость** к возрастным группам. Взрослый, ребёнок, младенец — разные действия.
4. **Проверьте совместимость** с приказом 220н. Если рекомендация расходится — обсудим отдельно.

## Стиль

- Простые формулировки. Без жаргона без расшифровки.
- Один шаг — одно действие.
- Пример лучше объяснения.
- Крупный шрифт на телефоне.

## Лицензия вклада

Отправляя Pull Request, вы соглашаетесь, что ваш вклад распространяется под **CC0**. Это значит, что ваш текст можно свободно копировать, печатать, распространять, изменять без указания авторства.
