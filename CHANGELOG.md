## [2.5.3] — 2026-10-23

### Added
- **16-я карточка:** справка «Закон о помощи» (юридическая справка для не медиков).
- **Дисклеймер «Not a medical device»** на каждом экране алгоритма (блок в начале detail-экрана).
- **Кнопка «Сброс»** для таймера приступа (сброс `sessionStorage` и обнуление счётчика).
- **Deep-link fix:** `#/seizure` и `#/cpr` при прямом открытии запускают таймер и Wake Lock.
- **`AGENTS.md`** — инструкция для coding-агентов (discovery-слой).
- **`devcard.json`** — машиночитаемая карточка автора (identity-слой).
- **`llms.txt`** — обновлён до 16 карточек, добавлены deep-links на все алгоритмы.

### Changed
- **Позиционирование:** «справочно-образовательный инструмент, не медизделие» — в README, `artifact.json` (`"medical": false`), `about`, footer.
- **Карточка «Инфаркт»:** формулировки про нитроглицерин и аспирин смягчены — «только по назначению врача», «по рекомендации диспетчера 112».
- **Карточка «Анафилаксия»:** формулировка про адреналин — «если обучен и есть автоинъектор».
- **Настройки метронома:** добавлено предупреждение о возможной блокировке экрана на некоторых устройствах.
- **`README.md`:** полностью переработан — добавлены блоки «Кто мы», «Принципы», «Источники», «Структура репозитория», «Установка», дисклеймер.
- **`artifact.json`:** обновлены URN, версия, `longDescription`, `releaseHistory`, `"medical": false`.

### Fixed
- **Wake Lock для CPR** не восстанавливался после переключения вкладки — добавлено восстановление в `visibilitychange` для `cpr` и `seizure`.
- **Таймер приступа** не сбрасывался при повторном открытии карточки — добавлена проверка `sessionStorage` при `startSeizureTimer()`.
- **`JSON.parse` для `stepProgress`** — обёрнут в `try/catch`, проверка на объект (защита от повреждённых данных в `localStorage`).
- **`buildCleanHtml()`** — при сохранении файла сбрасываются заголовок, описание и иконка detail-экрана (не остаётся «последний открытый алгоритм»).
- **`history.back()`** при выходе с экрана алгоритма — корректная обработка, если истории нет.
- **Иконки в `details.about`** — паспорт и предупреждения отображаются корректно.

### Security
- CSP не изменён: `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; connect-src 'none'`.
- 152-ФЗ: дисклеймер «Do not enter personally identifiable patient information» — в `about` и `README.md`.

## [2.5.0] — 2026-10-20

### Added
- **14 алгоритмов первой помощи:** СЛР, без сознания (дышит), кровотечение, инсульт, инфаркт, подавился (взрослый), подавился (ребёнок до года), анафилаксия, судороги, ожог, отравление, гипогликемия, обморожение, утопление.
- **2 справки:** как вызвать скорую, закон о помощи.
- **Метроном 110 BPM** для СЛР (Web Audio API).
- **Таймер приступа** для карточки «Судороги» (5 минут — сигнал к вызову 112).
- **Voice reading** (TTS) — чтение алгоритма вслух.
- **Избранное** (localStorage).
- **Фильтры:** все / срочно / важно / избранное.
- **Прогресс по шагам** (localStorage) — чек-лист шагов с галочками.
- **Тёмная/светлая тема** (авто по `prefers-color-scheme`).
- **Размер шрифта** — 3 варианта (А, А+, А++).
- **PWA:** manifest, service worker, иконки на главный экран.
- **Share и Save:** копирование ссылки, сохранение файла.
- **iPhone-first:** safe-area, 44px touch, крупный шрифт (19px base).
- **Skip-link, focus-trap, hash-routing** для доступности и навигации.
- **Print CSS** — `@page A4`, скрытие интерактивных элементов.
- **`prefers-reduced-motion`** — отключение анимаций.

### Changed
- Полный редизайн: красная тема для критичных экранов, крупная типографика.
- Унификация иконок (SVG, единый стиль).

### Security
- CSP: `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; worker-src 'self' blob:; img-src 'self' data: blob:; manifest-src 'self' blob:; font-src 'none'; connect-src 'none'; base-uri 'none'; form-action 'none'; object-src 'none'; frame-src 'none'`.
- `'use strict'` + IIFE + top-level try/catch.
- ES2015 (без async/await, без optional chaining).

## Формат версий

- **Major (X.0.0):** полный редизайн, несовместимые изменения в структуре.
- **Minor (2.X.0):** новые карточки, новые функции (голос, метроном, таймер).
- **Patch (2.5.X):** правки формулировок, дисклеймеры, багфиксы, обновление метаданных.
