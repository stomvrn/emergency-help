## [Unreleased]

## [2.4.0] — 2026-10-01

### Added

- 14-й алгоритм: анафилаксия
- Крупный шрифт по умолчанию для всех алгоритмов
- Оффлайн-режим: после первого открытия работает без сети

### Changed

- Переписаны формулировки алгоритмов: короче, проще
- Проверено по приказу Минздрава № 220н от 03.05.2024

### Fixed

- Исправлена опечатка в алгоритме «Судороги»
- Уточнена глубина нажатия при непрямом массаже сердца

## [2.3.0] — 2026-08-15
