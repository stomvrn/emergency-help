# AGENTS.md

## Инструкция для coding-агентов

Этот репозиторий — single-file HTML-приложение для оказания первой помощи. Не медизделие.

## Правила работы

- **Не добавляй внешние зависимости.** Нет CDN, нет npm, нет сборки.
- **Не меняй CSP.** `default-src 'none'; connect-src 'none'` — обязательно.
- **Не добавляй телеметрию.** Данные не покидают устройство.
- **Сохраняй single-file.** Всё в одном `index.html`.
- **Не меняй медицинский контент без источника.** Алгоритмы — по приказу Минздрава № 220н. Если правишь — указывай источник.
- **Дисклеймер обязателен.** «Not a medical device» — в футере, в meta, в about.

## Структура

- `index.html` — монолит (HTML + CSS + JS)
- `artifact.json` — паспорт артефакта (URN, версия)
- `llms.txt` — индекс для LLM
- `CHANGELOG.md` — история версий

## Стиль кода

- ES2015 (без async/await, без optional chaining)
- `'use strict'` + IIFE
- `try/catch` на верхнем уровне
- Все кнопки с `type`
- Все input с `aria-label` или `<label>`

## Проверка перед коммитом

1. Открыть `index.html` в браузере — работает.
2. Проверить CSP — не изменён.
3. Проверить URN — совпадает в `data-urn` и `meta[name="urn"]`.
4. Проверить версию — синхронно во всех местах.
